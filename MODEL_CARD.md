# Карточка модели

Модель относит фото листа к одному из восьми классов: здоровый лист или конкретная болезнь яблони, томата или картофеля.

## Ограничения

Модель смотрела лабораторные снимки на ровном фоне. Она не заменяет осмотр растения и не рассчитана на поле, другой ракурс, чужие культуры и болезни вне этих восьми классов. Несколько фото одного листа могли попасть и в train, и в test: сплит режет файлы, а не физический лист.

## Артефакт

Итоговый run MLflow: `5fd5ed281bce46088edaef1277d0d4fd`. Это EfficientNet-B0, дообучение верхних слоёв, early stopping по val, данные `v2_augmented`. На run стоит тег `production`.

Веса PyTorch: `artifacts/best_model.pt`, в git не входят, их держит DVC (`artifacts/best_model.pt.dvc`, md5 `f0996e849d89ec519a0ad9d0ce98bdd7`). Экспорт: `scripts/export_onnx.py`. Файл `artifacts/best_model.onnx` тоже не в git: указатель `artifacts/best_model.onnx.dvc`, md5 `0a032a9a2b40b6a062981946bc5b7dc9`. В контейнере его подключают томом, путь `MODEL_ARTIFACT_PATH=/models/best_model.onnx`.

Вход ONNX `input`: float32, `batch × 3 × 224 × 224`. Выход `logits`: float32, `batch × 8`. Препроцессинг инференса и test — `v1_baseline`, без обучающих аугментаций.

На `tests/fixtures/black_rot.jpg` логиты PyTorch и ONNX разошлись не больше чем на 9.54e-6 при допуске atol `1e-4`. Размер ONNX — 16061189 байт. Сто одиночных запросов на CPU: PyTorch 21.06 мс, ONNX 5.61 мс.

## Данные

Восемь классов PlantVillage, цвет, коммит источника `7f7ecc7e1eaca78107e3affe7cb5abd9427e139a`. Сплит 70/15/15, seed 42. Подробности и контрольные суммы — в `DATASET_CARD.md`.

## Оценка

Чекпоинт каждого опыта выбирался по macro-F1 на val. Test считался один раз в конце, одной и той же функцией. Задержка — среднее на 100 одинаковых примерах, CPU, один и тот же батч. Итоговая модель: максимальный test macro-F1 среди опытов, у которых задержка не больше 2× baseline. Лимит вышел 38.146 мс на снимок. Все три опыта уложились.

| Опыт | Test accuracy | Test macro-F1 | мс/снимок |
|---|---:|---:|---:|
| MobileNetV2, замороженный backbone, v1_baseline | 0.9604 | 0.9565 | 19.073 |
| MobileNetV2, дообучение верхних слоёв, v2_augmented | 0.9852 | 0.9818 | 18.695 |
| EfficientNet-B0, дообучение и early stopping, v2_augmented | 0.9899 | 0.9870 | 22.465 |

Выбран третий опыт: у него наибольший test macro-F1, а задержка 22.465 мс меньше лимита.

## Риски

- Фон и освещение в поле другие, точность упадёт.
- Редкий класс `Potato___healthy` в данных самый маленький, 152 снимка.
- Путаница внутри одной культуры вероятнее, чем между культурами: классы визуально близки.
- Ответ сервиса — это имя класса и уверенность, не диагноз и не рекомендация по обработке.
